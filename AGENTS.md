# Правила для ИИ-агентов (Claude, Codex, Cursor и др.)

Проект — вертикальная визуальная новелла на собственном движке **Sova VN**:
чистый HTML/CSS/JS, без сборки и зависимостей, хостинг — GitHub Pages.

## Сначала прочитай

| Задача | Документ |
|---|---|
| Писать/править сцены | `docs/SCENE_FORMAT.md` — **полный справочник шагов** |
| Менять движок | `docs/ENGINE.md` — архитектура и инварианты |
| Мини-игры | `docs/MINIGAMES.md` |
| Арт, звук, CG | `docs/ASSETS.md` |
| Конструктор (редактор для человека) | `docs/EDITOR.md` |

## Где что менять

- **Сюжет, персонажи, ассеты, настройки игры** → только `game/` (сцены, `game.json`, `manifest.json`).
  Код движка для этого не трогать.
- **Движок** (`engine/`) универсален: в нём не должно быть ничего про конкретную игру.
- **Формат шагов** описан в одном месте — `engine/js/schema.js`. Его используют движок,
  Конструктор и линтер. Новый тип шага = правка `schema.js` + `parser.js` + `docs/SCENE_FORMAT.md`
  (+ форма в `editor/editor.js`). Чек-лист — `docs/ENGINE.md`.

## Обязательно после правок

```bash
node tools/lint_scenes.mjs        # после ЛЮБОЙ правки game/ — должно быть «✓ ошибок нет»
node tools/smoke_test.mjs         # после правки engine/ (нужен playwright, см. README)
```

Проверка глазами: `node tools/serve.mjs` → `http://localhost:8000/?scene=<id>&at=<метка>&debug=1`.

## Правила записи сцен (коротко)

1. Один шаг = одно действие: `{ "say": {...} }`, `{ "show": {...} }`. Лишние ключи — ошибка линтера.
2. Каждая переменная объявляется в `game.json → vars` до использования.
3. Сцена заканчивается `end`, `scene` или `goto` — иначе линтер выдаст «сцена обрывается».
4. Имена `who` — из `manifest.json` (ключ или `name`) либо из `game.json → speakers`.
5. JSON с отступом 2 пробела, UTF-8, кавычки «ёлочки» в тексте — можно.
6. Нет «фальшивых» выборов: каждая опция даёт свою реакцию (`narr`, `goto`, `set`, `memo`).

## Нельзя

- Писать в `engine/` игровую логику или тексты.
- Подключать CDN, npm-пакеты в рантайм, сборщики — игра должна открываться как статика.
- Удалять/переименовывать ключи `localStorage` без миграции (у игроков пропадут сейвы).
