## 6. Технические заметки

- Фоны сейчас **720×1280**, а в `plan.md` заявлено 1080×1920. Новые делать сразу
  1080×1920: на телефоне 720p-фон мылит, и разница со новыми будет заметна.
- Пайплайн: `python3 tools/make_sprite.py raw/x.png --bg -o game/assets/bg/<id>.webp`,
  затем `<id>` в `game/assets/bg/index.json`. Спрайты — без `--bg`, 675×1200.
- Спрайты: полный рост, ноги у нижнего края, взгляд/разворот влево (движок зеркалит
  для слота `left`), `height` одинаковая у всех эмоций персонажа.
- Важное держать в центральных 80% ширины фона — края обрезаются на 20:9.
- После любой правки: `node tools/lint_scenes.mjs` (должно быть «✓ ошибок нет»).
- Проверка глазами: `?scene=ch2_c6&at=c6_h_a&debug=1`, `?scene=ch2_i3&at=c_i3_hub&debug=1`,
  `?scene=ch2_c7&at=c7_cloak&debug=1`.
- Имена: `hq_*` — штаб, `town_*` — город, `wall_*` — стена, `ch2_*` — CG главы.
