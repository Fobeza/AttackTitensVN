# Sova VN — архитектура движка

Универсальный движок вертикальной визуальной новеллы (9:16, mobile-first).
Чистый HTML/CSS/JS, **ноль зависимостей и сборки** — открывается как статика.

**Правило №1:** всё про конкретную игру (тексты, персонажи, ассеты) — в `game/`.
`engine/` универсален и не должен знать ни одного имени героя.

## Файлы

```
index.html               оболочка: DOM кадра 9:16 + подключение скриптов (порядок важен)
engine/css/engine.css    вся вёрстка; цвета — CSS-переменные (тема из game.json → theme)
engine/js/
  schema.js     ФОРМАТ ШАГОВ: типы, проверка сцен (lintScene), условия (test). UMD — работает и в Node
  state.js      VN.game (партия), applySet, test, fmt({{var}}), memo, error, persist, debug
  save.js       слоты 1–9 + auto + quick, снапшот с якорем, экспорт/импорт строкой
  audio.js      BGM-петли с фейдами, SFX, перебор форматов ogg → mp3 → wav
  renderer.js   фон, CG, спрайты (слоты, переезд, эмоции, фокус), тряска, вспышка, восстановление
  ui.js         ввод, реплики (печатная машинка), карточки, выборы, авто/пропуск, панели, тосты
  minigames.js  реестр и запуск мини-игр
  minigames/    встроенные мини-игры: timing.js, quiz.js
  parser.js     исполнитель сцен: цикл по шагам, метки, переходы, поколения запусков
  menu.js       главное меню, новая игра
  main.js       запуск: game.json → тема → настройки → меню / параметры адреса
editor.html, editor/     Конструктор (использует engine/js/schema.js)
tools/                   lint_scenes.mjs, smoke_test.mjs, serve.mjs, make_sprite.py, make_sfx.py
```

Скрипты — обычные `<script>` (не модули), общий объект `window.VN`.

## Жизненный цикл

1. `main.js`: читает `game/game.json` → `VN.cfg`, применяет тему, грузит настройки и
   постоянные данные, вешает ввод, разбирает параметры адреса, показывает меню.
2. «Начать» → `VN.menu.newGame()` → `VN.parser.run(startScene)`.
3. `parser.run()` грузит сцену, строит таблицу меток, применяет `bg`/`bgm` сцены,
   делает автосейв и исполняет шаги по очереди.
4. Шаги, ждущие игрока (`say`, `narr`, `card`, `choice`, `minigame`, `wait`), возвращают
   Promise; цикл продолжается после его разрешения.

## Инварианты (не ломать)

**Один исполнитель.** Каждый `run()` получает номер поколения `_gen`. Любой `await` в цикле
сопровождается проверкой `alive()`: если запущено что-то новее (новая игра, загрузка, выход в меню),
старый цикл молча выходит. `VN.parser.stop()` увеличивает поколение и отменяет ожидания.

**Одно ожидание.** Всё, что ждёт игрока, регистрирует себя в `VN.ui._wait`:
`{ advance(), cancel(), kick?() }`. Тап/пробел зовут `advance()`, перезапуск — `cancel()`
(Promise разрешается `false`/`null`, цикл видит это и выходит), смена режима авто/пропуск — `kick()`.

**Один обработчик ввода.** Клик по `#stage` (кроме HUD, выбора, мини-игры) и клавиатура —
в `VN.ui.initInput()`. Панели (`#overlay`) лежат вне `#stage`, поэтому клики по ним не
продвигают диалог. Не вешай новых `click` на `#stage`/`#dialog`.

**Метки строятся при каждом входе в сцену**, в том числе при загрузке сейва с середины.

**Состояние картинки — в `VN.game.visual`** (`bg`, `cg`, `bgm`, `sprites{slot:{char,expr,height}}`).
Его пишут только `renderer`/`audio`, его читает сейв и `restoreVisual()`.

**Спрайты.** Слоты `left` 22% / `center` 50% / `right` 78%. Один герой — один слот:
`show` в другой слот переносит его (`_move`). Все исходники смотрят влево; `left` зеркалится.
Высота — доля высоты сцены из `manifest.json` (окно диалога режет фигуру по пояс).

**Реплика всегда помещается в окно.** `VN.ui._paginate()` режет длинный текст на страницы по предложениям (потом по словам): каждая влезает в `#dialog` без прокрутки, тап листает страницы, авто и пропуск работают постранично. В бэклог текст попадает целиком. Не ставь `overflow` и фиксированные размеры на `#text` без проверки `tools/smoke_test.mjs`.

**Выбор помнит вопрос.** Парсер передаёт в `VN.ui.choice(options, prompt)` реплику (`say` или `narr`) непосредственно перед `choice` (метки не считаются), и она остаётся видимой над кнопками (`.choice-prompt`, до 3 строк).

**Ошибки видимы.** `VN.error(msg)` = красный тост + `console.error`. Битый переход, нет файла,
падение мини-игры, исключение JS — всё всплывает, а не тонет в консоли.

## Сохранения

| Ключ localStorage | Что |
|---|---|
| `<storage>_saves_v1` | слоты `1`…`9`, `auto`, `quick` |
| `<storage>_settings` | скорость текста, авто, громкость, размер текста, пропуск непрочитанного |
| `<storage>_persist` | прочитанные шаги (для пропуска), открытые CG, сыгранные мини-игры |
| `__vn_preview` | сцена из Конструктора для `?preview=1` |
| `vn_editor_wip::<id>` | черновики Конструктора |

Снапшот (`v: 2`): `scene`, `step`, `len` (число шагов сцены), `anchor` (ближайшая метка выше +
смещение), `vars`, `memos`, `visual`, `history`, `line` (последняя реплика для списка слотов).
Если сцену правили и длина изменилась — шаг восстанавливается по `anchor`. Поэтому **ставь метки**
в длинных сценах — это делает сейвы устойчивыми к правкам. Старые сейвы `v: 1` тоже читаются.

Автосейв: при входе в сцену с начала и перед каждым выбором. «Продолжить» = самый свежий сейв.

## Управление

| Действие | Мышь/тач | Клавиши |
|---|---|---|
| дальше / допечатать | тап по сцене | Пробел, Enter, → |
| выбор | кнопка | 1–9 |
| пауза | ⚙ | Esc (Esc же закрывает панель) |
| бэклог | ↻ | ↑ или B |
| авто | ▶ | A |
| пропуск прочитанного | ⏩ | S (тап — стоп) |
| быстрое сохранение / загрузка | Пауза → ⚡ | F5 / F9 |

Пропуск останавливается на выборе, мини-игре и непрочитанном тексте (если в настройках не включено иное).

## Отладка

Параметры адреса:
- `?scene=<id>` — сразу в сцену; `&at=<метка>` или `&at=<номер шага>` — с нужного места;
- `&vars=trust:3,f_met:true,route:levi` — стартовые значения;
- `&debug=1` — зелёная строка вверху: `сцена:шаг тип · переменные`;
- `?preview=1` — сцена из Конструктора («▶ Тест»).

В консоли: `VN.game` (состояние), `VN.parser.sceneData()`, `VN.save.snapshot()`.

## Как расширять

### Новый тип шага — чек-лист
1. `schema.js`: добавить в `STEPS` (заголовок, допустимые доп. ключи) и проверку в `lintScene()`
   (и, если шаг прыгает, — в анализ достижимости).
2. `parser.js`: ветка в `switch (t)`. Если шаг ждёт игрока — сделай его через `VN.ui._wait`
   и проверяй результат/`alive()` после `await`.
3. Если шаг меняет картинку — пиши состояние в `VN.game.visual` и восстанавливай в `restoreVisual()`.
4. `editor/editor.js`: `makeStep()`, `summarize()`, форма в `renderForm()` (минимум — работает «JSON шага»).
5. `docs/SCENE_FORMAT.md`: строка в шпаргалке + раздел.
6. `tools/smoke_test.mjs`: проверка, если поведение нетривиальное. Прогнать линтер и смоук.

### Новая мини-игра
См. `docs/MINIGAMES.md`. Игровые — в `game/minigames/`, встроенные (универсальные) — в
`engine/js/minigames/` + `<script>` в `index.html` + id в `schema.BUILTIN_MINIGAMES`.

### Новая настройка
`VN.ui.DEFAULTS` + поле в `settingsUI()` + применение в `applySettings()`.
