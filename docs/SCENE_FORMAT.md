# Формат сцен — полный справочник

Источник правды — `engine/js/schema.js`. Если документ и схема расходятся, права схема
(и это баг документа — поправь). После любой правки: `node tools/lint_scenes.mjs`.

## Сцена

Файл `game/scenes/<id>.json`, id вписан в `game/game.json → scenes`.

```json
{
  "id": "ch1",
  "title": "Глава 1",
  "bg": "hq_corridor",
  "bgm": "tension_pad",
  "steps": [ ...шаги ]
}
```

| Поле | Обяз. | Что делает |
|---|---|---|
| `id` | нет | должен совпадать с именем файла (если указан) |
| `title` | нет | для людей; в меню сейвов берётся из `game.json → scenes[].title` |
| `bg` | нет | фон при входе в сцену (`null` — убрать) |
| `bgm` | нет | музыка при входе (`null` — тишина) |
| `steps` | да | массив шагов |

Шаги выполняются сверху вниз. **Каждый шаг — объект с одним ключом-типом**
(у `minigame` и `scene` есть разрешённые доп. ключи). Сцена обязана заканчиваться
`end`, `scene` или `goto` на всех путях — линтер это проверяет.

## Шаги — шпаргалка

| Шаг | Пример | Ждёт тапа |
|---|---|---|
| реплика | `{ "say": { "who": "Леви", "text": "Сядь.", "expr": "serious" } }` | да |
| нарратив | `{ "narr": "Вода в чашке дрожит." }` | да |
| карточка | `{ "card": { "title": "Глава 1", "sub": "Подозрение" } }` | да |
| спрайт | `{ "show": { "char": "levi", "expr": "serious", "slot": "right", "enter": "right" } }` | |
| убрать | `{ "hide": { "slot": "right", "exit": "fade" } }` / `{ "hide": { "char": "levi" } }` / `{ "hide": "all" }` | |
| фон | `{ "bg": "hq_mess" }` / `{ "bg": null }` | |
| CG | `{ "cg": "tea_party" }` / `{ "cg": null }` | |
| музыка | `{ "bgm": "tension_pad" }` / `{ "bgm": null }` | |
| звук | `{ "sfx": "door_metal" }` | |
| переменные | `{ "set": { "trust": 1, "f_met": true, "lei": { "=": 0 } } }` | |
| памятка 🕊 | `{ "memo": "Леви это запомнит" }` | |
| выбор | `{ "choice": [ { "text": "…", "goto": "…" } ] }` | да |
| метка | `{ "label": "c1_tea" }` | |
| переход | `{ "goto": "c1_tea" }` | |
| условие | `{ "if": { "var": "trust", "min": 2, "goto": "c1_ok", "else": "c1_no" } }` | |
| пауза | `{ "wait": 800 }` | (сама) |
| тряска | `{ "shake": "small" }` / `"big"` | |
| вспышка | `{ "flash": "#fff" }` | |
| мини-игра | `{ "minigame": "quiz", "params": {…}, "win": "…", "lose": "…" }` | да |
| другая сцена | `{ "scene": "ch2" }` / `{ "scene": "ch2", "at": "c2_start" }` | |
| конец | `{ "end": { "title": "Конец главы 1", "sub": "…" } }` | да |

## Текст

### say — реплика
```json
{ "say": { "who": "Леви", "text": "Сядь.", "expr": "serious" } }
```
- `who` — ключ персонажа из `manifest.json` (`"levi"`) **или** его `name` (`"Леви"`).
  На плашке всегда показывается `name`. Говорящий подсвечивается, остальные на экране притушены.
- NPC без спрайта (`"???"`, `"Голос"`) — впиши имя в `game.json → speakers`, иначе линтер предупредит.
- `expr` (необяз.) — сменить эмоцию говорящего, если он стоит на экране. Экономит отдельный `show`.
- Мысли героини: `who` = её имя, текст в скобках: `"(Опять он хмурится…)"`.
- Переменные в тексте: `"Доверие: {{trust}}"` (переменная должна быть объявлена).

### narr — повествование
`{ "narr": "Шаги стихли." }` — курсивом, без плашки имени, снимает подсветку.

### card — полноэкранная плашка
`{ "card": "Прошло три дня" }` или `{ "card": { "title": "Глава 2", "sub": "Крылья и клятва" } }`.

## Картинка

### show — показать спрайт / сменить эмоцию
```json
{ "show": { "char": "levi", "expr": "serious", "slot": "center", "enter": "fade" } }
```
| Поле | Значения | По умолч. |
|---|---|---|
| `char` | ключ из `manifest.json` | — |
| `expr` | эмоция этого персонажа | `neutral` |
| `slot` | `left` · `center` · `right` | `center` |
| `enter` | `fade` · `left` · `right` · `rise` | `fade` |
| `height` | доля высоты сцены (перекрывает manifest) | из manifest |

- Тот же герой в том же слоте → плавная смена эмоции (спрайт не двигается).
- Герой уже стоит в **другом** слоте → он **переезжает** (без дубля). Если целевой слот занят
  другим — тот растворяется.
- В занятый слот ставится другой герой → мягкая замена (fade-своп).
- Слот `left` зеркалится автоматически: все спрайты нарисованы смотрящими влево.

### hide — убрать спрайт
`{ "hide": { "slot": "left" } }`, `{ "hide": { "char": "levi", "exit": "right" } }`, `{ "hide": "all" }`.
`exit`: `fade` · `left` · `right`.

### bg, cg
- `{ "bg": "hq_mess" }` — фон из `game/assets/bg/<имя>.webp` (имя должно быть в `bg/index.json`).
- `{ "cg": "tea_party" }` — полноэкранная картинка поверх спрайтов, под диалогом.
  Файл `game/assets/cg/<id>.webp`, id — в `game.json → gallery`. Увиденные CG открываются в галерее.
  `{ "cg": null }` — убрать.

### shake, flash, wait
- `{ "shake": "small" }` / `"big"` / `true` — тряска сцены.
- `{ "flash": "#fff" }` / `true` — вспышка цветом.
- `{ "wait": 800 }` — пауза в мс (1…20000); в режиме пропуска не ждёт.

## Звук
- `{ "bgm": "tension_pad" }` — петля из `game.json → audio.bgm`; `null` — тишина. Повтор той же — ничего.
- `{ "sfx": "door_metal" }` — разовый звук из `audio.sfx`.
- Файлы: `game/assets/audio/<имя>.ogg` и/или `.mp3` (движок берёт что поддерживает браузер, затем `.wav`).

## Переменные и состояние

### Объявление (game.json)
```json
"vars": {
  "trust": { "default": 0, "title": "Доверие" },
  "f_met_levi": { "default": false, "title": "Встретила Леви" }
}
```
Необъявленная переменная в `set`, `if`, `{{…}}` — **ошибка линтера**.
Соглашение: `f_…` — флаги (true/false), остальное — числа или строки.

### set
```json
{ "set": { "trust": 1, "lei": -2, "f_met_levi": true, "route": "levi", "erw": { "=": 0 } } }
```
- число → **прибавить** (может быть отрицательным);
- строка / `true` / `false` → присвоить;
- `{ "=": значение }` → присвоить что угодно, в т.ч. число.

### memo 🕊 — памятка
`{ "memo": "Леви это запомнит" }` — строка попадает в Пауза → «Память» (без повторов).
Тост показывается, если `game.json → "memoToast": true`. Статистика (`set`) никогда не показывается игроку —
вес выбора передаётся только памятками.

## Ветвление

### label / goto
Метки — латиница, цифры, `_ . -`; уникальны в сцене. Соглашение: `<сцена>_<что>` (`c1_tea`, `c1_tea_r2`).

### Условия
Одинаковы для `if` и для опций выбора:
```json
{ "var": "trust", "min": 2 }               // trust >= 2
{ "var": "trust", "min": 1, "max": 3 }     // 1 <= trust <= 3
{ "var": "f_met_levi", "eq": true }        // флаг установлен (не объявленный = false/0)
{ "var": "route", "ne": "erwin" }          // не равно
{ "all": [ {…}, {…} ] }                    // все условия
{ "any": [ {…}, {…} ] }                    // хотя бы одно
```

### if
```json
{ "if": { "var": "truth", "min": 3, "goto": "c1_secret", "else": "c1_plain" } }
{ "if": { "all": [ { "var": "lei", "min": 5 }, { "var": "f_lied", "eq": false } ], "goto": "c1_true_end" } }
```
Без `else` при невыполнении — идём на следующий шаг.

### choice
```json
{ "choice": [
  { "text": "Кивнуть", "set": { "trust": 1 }, "goto": "c1_ok" },
  { "text": "Промолчать", "narr": "Леви ждёт. Потом отворачивается.", "memo": "Леви запомнил молчание" },
  { "text": "Давнее воспоминание", "if": { "var": "truth", "min": 3 }, "goto": "c1_hint" },
  { "text": "Тайный вариант", "if": { "var": "f_secret", "eq": true }, "locked": "hide", "goto": "c1_x" }
] }
```
| Поле опции | Что делает |
|---|---|
| `text` | текст кнопки (обяз.), поддерживает `{{var}}` |
| `goto` | куда перейти; без него — следующий шаг после выбора |
| `set` | изменить переменные |
| `narr` | короткий отклик сразу после выбора |
| `memo` | памятка 🕊 |
| `if` | условие; не выполнено → кнопка с 🔒 и неактивна |
| `locked` | `"hide"` — при невыполненном условии кнопку не показывать вовсе |

Перед каждым выбором — автосейв. Клавиши 1–9 выбирают опцию.

## Мини-игры
```json
{ "minigame": "quiz",
  "params": { "questions": [ { "q": "Какая стена внешняя?", "options": ["Сина", "Роза", "Мария"], "answer": 2 } ] },
  "var": "quiz_score", "onWin": { "truth": 1 }, "onLose": { "trust": -1 },
  "win": "c1_quiz_ok", "lose": "c1_quiz_fail", "skippable": true, "skipAs": "lose" }
```
| Ключ | Что делает |
|---|---|
| `minigame` | id: встроенные `timing`, `quiz` или из `game.json → minigames` |
| `params` | настройки конкретной игры (см. `docs/MINIGAMES.md`) |
| `var` | записать очки (`score`) в переменную |
| `onWin` / `onLose` | `set`-блок по результату |
| `win` / `lose` | метки перехода по результату (без них — следующий шаг) |
| `skippable` | `false` — убрать кнопку «Пропустить» (по умолчанию можно) |
| `skipAs` | пропуск засчитывается как `"lose"` (по умолч.) или `"win"` |

## Переходы между сценами
- `{ "scene": "ch2" }` — перейти в начало сцены `ch2` (текущая на этом заканчивается).
- `{ "scene": "ch2", "at": "c2_after_tea" }` — в метку другой сцены.
- `{ "end": { "title": "Конец главы 1", "sub": "Продолжение следует" } }` — финальная плашка → меню. `{ "end": true }` — без текста.

При входе в сцену (с начала) делается автосейв.

## game.json — все поля

| Поле | Что это |
|---|---|
| `title`, `titleHtml`, `subtitle`, `footer` | тексты меню (`titleHtml` допускает `<br>`) |
| `about` | HTML для «Об игре» |
| `startScene` | первая сцена «Начать» |
| `storage` | префикс ключей `localStorage` (латиница). **Не менять** после релиза — пропадут сейвы |
| `paths` | `{ "scenes": "game/scenes", "assets": "game/assets" }` |
| `menuBg`, `menuBgm` | фон и музыка меню |
| `memoToast` | показывать ли тост при памятке |
| `theme` | CSS-переменные: `--paper`, `--paper-dim`, `--bg-dark`, `--panel`, `--accent`, `--good`, `--bad` |
| `vars` | переменные: `{ имя: { default, title } }` |
| `speakers` | имена говорящих без спрайта (NPC, «???») |
| `scenes` | `[ { id, title } ]` — все сцены игры |
| `audio` | `{ bgm: [...], sfx: [...] }` — имена файлов без расширения |
| `gallery` | `[ { id, title } ]` — CG для шага `cg` и галереи |
| `galleryText` | текст галереи, когда CG ещё нет |
| `minigames` | игровые мини-игры: `{ "id": "game/minigames/id.js" }` |
| `debug` | `true` — всегда показывать строку отладки |

## Плейбук стиля

1. Начало сцены: `bg` + `bgm` полями сцены, затем `show` с `enter`, затем реплики.
2. Собеседник долго стоит в одном слоте; эмоции меняй через `say.expr`.
3. Главный собеседник — `center` или `right`; второй — `left` (он зеркалится в сцену).
4. Нет фальшивых выборов: если опции сходятся в одну точку, у каждой — своя реакция
   (`narr` в опции или микроветка `…_r0/_r1/_r2` → `goto` в общую метку).
5. Перед большой развилкой выпиши карту: куда ведёт каждый `goto` и где ветки сходятся.
6. Памятки 🕊 — только в действительно важных точках (2–4 на главу).
7. Длинная реплика — до ~220 символов; больше — разбей на две.
8. После правок: `node tools/lint_scenes.mjs` и `?scene=<id>&at=<метка>&debug=1`.

## Рецепты

**Микроветка с общим продолжением**
```json
{ "choice": [
  { "text": "Поблагодарить", "goto": "c1_tea_r0", "set": { "lei": 1 } },
  { "text": "Съязвить", "goto": "c1_tea_r1" }
] },
{ "label": "c1_tea_r0" },
{ "say": { "who": "Леви", "expr": "soft", "text": "…Не за что." } },
{ "goto": "c1_tea_merge" },
{ "label": "c1_tea_r1" },
{ "say": { "who": "Леви", "expr": "annoyed", "text": "Остроумно. Пей." } },
{ "label": "c1_tea_merge" }
```

**Выбор куратора и вечер по нему**
```json
{ "choice": [
  { "text": "Леви", "set": { "curator": "levi" } },
  { "text": "Ханджи", "set": { "curator": "hange" } }
] },
{ "if": { "var": "curator", "eq": "levi", "goto": "c1_eve_levi", "else": "c1_eve_hange" } }
```
