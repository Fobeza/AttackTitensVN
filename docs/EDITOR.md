# Конструктор сцен — как пользоваться

`node tools/serve.mjs` → `http://localhost:8000/editor.html`.

Конструктор использует ту же схему шагов и ту же проверку, что движок и линтер
(`engine/js/schema.js`), поэтому всё, что он пропускает, будет работать в игре.

## Экран

- **Слева** — сцены из `game/game.json → scenes`; ниже — фон и музыка сцены.
- **Центр** — шаги: номер, тип, кратко. Справа у шага: **✗** — ошибка, **~** — предупреждение.
- **Справа** — форма выбранного шага. Вверху формы — проблемы этого шага.
  Внизу — **«{ } JSON шага»**: любой шаг можно править как JSON (применяется, когда JSON корректен).

## Кнопки

| Кнопка | Что делает |
|---|---|
| ＋ Новая сцена | спрашивает id и название, создаёт заготовку |
| ⇪ Импорт | открыть JSON сцены с диска |
| 📁 Папка проекта | (Chrome/Edge на компьютере) подключить корень проекта — дальше сохранение пишет прямо в файлы |
| ⇩ Экспорт / 💾 Сохранить (Ctrl+S) | без папки — скачать `<id>.json` (положи в `game/scenes/`); с папкой — записать `game/scenes/<id>.json` и вписать новую сцену в `game.json` |
| ▶ Тест | играть сцену в движке с начала (новая вкладка, со строкой отладки) |
| ▶ С шага | играть с выбранного шага |
| ✓ Проверка | список всех проблем; клик по строке — к шагу |
| ＋ Шаг ниже / ↑ ↓ / ⧉ / 🗑 | добавить шаг выбранного типа, двигать, копировать, удалить |

## Подсказки по формам

- **Реплика:** «Эмоция» меняет выражение говорящего, если он на экране. Своё имя (NPC) —
  «✏️ своё имя…»; чтобы линтер не ругался, впиши его в `game.json → speakers`.
- **Переменные (set):** `+1` / `-2` — прибавка; `=0` — присвоить число; `true`/`false`/текст — присвоить.
- **Условие опции:** `trust>=2`, `lei>=1<=3`, `f_met==true`, `route!="erwin"` или JSON `{"all":[…]}`.
- **Убрать спрайт:** по слоту, по персонажу или всех.
- **Спрайт:** если герой уже стоит в другом слоте, он сам переедет — отдельный hide не нужен.
- Переменные должны быть объявлены в `game.json → vars` (там же их названия).

## Черновики

Каждая правка автосохраняется в браузере (точка ● в шапке = есть несохранённое в файл).
Сохранение/экспорт очищает черновик. Черновик живёт только в этом браузере.

## После

`node tools/lint_scenes.mjs` — та же проверка плюс файлы на диске (существуют ли картинки и звуки).
