# Мини-игры

Мини-игра — полноэкранный слой поверх сцены. Перед стартом показывается экран правил
(`help`) с кнопкой «Начать»; в углу — «Пропустить» (если не запрещено шагом).

## Вызов из сцены

```json
{ "minigame": "timing", "params": { "rounds": 3, "need": 2 },
  "var": "tea_score", "onWin": { "lei": 1 }, "win": "c2_tea_ok", "lose": "c2_tea_bad" }
```
Все ключи шага — в `docs/SCENE_FORMAT.md → Мини-игры`. Результат игры — `{ win, score }`:
`score` пишется в `var`, затем применяется `onWin`/`onLose`, затем переход на `win`/`lose`.
Пропуск = `{ win: skipAs === "win", score: 0 }`.

## Встроенные

### timing — «поймай момент»
Маркер бегает по шкале, игрок жмёт кнопку, когда он в зелёной зоне. Годится для
чаепития (заварка в зелёной зоне), уворотов, стрельбы.

| params | По умолч. | |
|---|---|---|
| `rounds` | 3 | раундов |
| `need` | 2 | попаданий для победы |
| `speed` | 1 | множитель скорости (растёт с каждым раундом) |
| `zone` | 0.22 | ширина зелёной зоны, доля шкалы |
| `button` | «Сейчас!» | надпись на кнопке |
| `title`, `help` | | заголовок и правила (перекрывают стандартные) |

`score` = число попаданий.

### quiz — вопросы с вариантами
Загадки, экзамен, допрос «держи версию».

```json
"params": {
  "need": 2,
  "questions": [
    { "q": "Какая стена внешняя?", "options": ["Сина", "Роза", "Мария"], "answer": 2, "hint": "Мария — самая внешняя." },
    { "q": "Что на эмблеме Разведкорпуса?", "options": ["Крылья", "Роза", "Единорог"], "answer": 0 }
  ]
}
```
`answer` — индекс верного варианта с 0; `hint` показывается после неверного ответа;
`need` — сколько верных для победы (по умолч. все). `score` = число верных.

## Игровые мини-игры (`game/minigames/`)

### cleaning — «Уборка»
Оттереть пятна с камня пальцем или мышью до конца таймера (canvas: слой грязи стирается щёткой).

| params | По умолч. | |
|---|---|---|
| `time` | 20 | секунд на уборку |
| `need` | 0.85 | доля чистоты для победы |
| `brush` | 20 | радиус щётки, px |

`score` = процент чистоты. При 97%+ игра заканчивается досрочно.

### lab — «Лаборатория»
Дедукция: по записям из «Дневника Ханджи» вывести единственный порядок четырёх реагентов и перетащить их в ячейки (перетаскивание или тап). После «Смешать» подсказка: сколько реагентов на своих местах.

| params | По умолч. | |
|---|---|---|
| `tries` | 3 | попыток смешать |
| `puzzle` | случайная | номер задачи (0 или 1) |

`score` = оставшиеся попытки. Задачи лежат в `lab.js` (`PUZZLES`): у каждой решение должно быть единственным (проверь перебором перестановок). Для автотестов решение лежит в `root.dataset.solution`.

Стили игровой мини-игры вставляются из её же файла через `<style id="mg-…-css">` — отдельный CSS не нужен.

### tea — «Чаепитие»
Зажми кнопку, чашка наполняется; отпусти, когда уровень в зелёной зоне. Зона у каждой чашки уже предыдущей. Перелил — чашка пролита.

| params | По умолч. | |
|---|---|---|
| `cups` | 3 | число чашек |
| `need` | 2 | сколько удачных нужно для победы |
| `zones` | `[0.26, 0.2, 0.15]` | ширина зоны по чашкам (доля шкалы) |
| `speed` | 0.5 | доля шкалы в секунду |

`score` = удачные чашки. Для автотестов текущая зона лежит в `root.dataset.zone`, уровень — в `root.dataset.level`.

### dispatch — «Сверка донесений»
Два донесения об одном событии: найти строки второго, противоречащие первому.

| params | |
|---|---|
| `a` | `{ title, lines: [строки] }` — эталон |
| `b` | `{ title, lines: [{ t, x }] }` — проверяемое; `x: true` у противоречащих строк |
| `mistakes` | сколько ошибочных касаний допустимо (по умолч. 2) |

`score` = найдено противоречий; победа, если найдены все.

### cipher — «Знаки жетона»
Продолжить ряд знаков и восстановить выскобленный. Без `params` берутся три встроенных ряда
(поворот, каждый третий перевёрнут, чередование с ростом). Свои: `rounds: [{ seq, options, answer }]`, `mistakes` (по умолч. 2).
В `root.dataset.answer` лежит верный знак текущего ряда (для автотестов).

### evidence — «Доска улик»
Связать найденные улики с выводами. Игра **читает переменные сцены** (`ctx.vars`): улика показывается, только если её `var` истинна или > 0.
Вывод, для которого в руках нет ни одной подходящей улики, помечается «нет улик» и не блокирует победу.

| params | |
|---|---|
| `goals` | `[{ text, ok: ["id улики", …] }]` |
| `clues` | `[{ id, text, var }]`; улика без `var` показывается всегда (можно использовать как отвлекающую) |
| `need` | сколько выводов нужно доказать (по умолч. 2) |

`score` = доказано выводов. Ошибочные касания не штрафуются, но видны.

## Своя мини-игра

1. Файл `game/minigames/<id>.js`:

```js
VN.minigames.register("tea", {
  title: "Чаепитие",
  help: "Держи кнопку, пока стрелка в зелёной зоне.",
  start(ctx) {
    // ctx.root      — пустой <div>, рисуй игру в нём (стили — свои классы или mg-btn, mg-status)
    // ctx.params    — params из шага сцены
    // ctx.vars      — копия переменных (только чтение)
    // ctx.sfx(name) — звук из game.json → audio.sfx
    // ctx.toast(t)  — короткое сообщение
    // ctx.onCleanup(fn) — снять таймеры/обработчики при выходе (в т.ч. при пропуске)
    // ctx.finish({ win, score }) — закончить игру (один раз)
    const btn = document.createElement("button");
    btn.className = "mg-btn";
    btn.textContent = "Заварить";
    btn.onclick = () => ctx.finish({ win: true, score: 1 });
    ctx.root.appendChild(btn);
  }
});
```

2. Подключить в `game/game.json`:
```json
"minigames": { "tea": "game/minigames/tea.js" }
```
Скрипт догружается при первом запуске. Линтер проверяет, что файл есть и в нём
вызывается `register("tea", …)`.

3. Проверить: шаг `{ "minigame": "tea" }` в сцене → `?scene=<id>&at=<метка>`.

### Правила
- Всё, что запущено (таймеры, `requestAnimationFrame`, обработчики на `document`), снимай в `onCleanup`:
  игрок может нажать «Пропустить» или выйти в меню в любой момент.
- Не трогай DOM вне `ctx.root` и не меняй `VN.game` напрямую — результат только через `finish`.
- Исключение в `start()` не роняет игру: движок покажет ошибку и засчитает пропуск.
- Универсальную мини-игру (полезную любой новелле) можно перенести в `engine/js/minigames/`,
  добавить `<script>` в `index.html` и id в `BUILTIN_MINIGAMES` (`engine/js/schema.js`).
